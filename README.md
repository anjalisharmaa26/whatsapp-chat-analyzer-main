# 💬 WhatsApp Chat Analyzer

A powerful and interactive WhatsApp Chat Analyzer built using **Python** and its data analysis libraries. This tool allows users to upload exported chat files and gain meaningful insights through statistics and visualizations.

## 📊 Features

- Upload and parse WhatsApp chat text files
- Show top statistics: total messages, words, media, and links
- Identify most active users in a group chat
- Generate word clouds and emoji analysis
- Visualize monthly, daily, and hourly activity trends
- Create heatmaps and activity timelines

## 🛠️ Tech Stack

- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- WordCloud  
- URLEXtract  
- Collections  
- Streamlit *(for the interactive frontend)*
